# AI Product Management Roadmap

## North Star

Build AI products that solve a real user problem and can be measured, tested, improved, and operated responsibly.

## Phase 1 — Product Foundations
- Product discovery
- User interviews
- Problem statements
- Personas
- Jobs-to-be-done
- User stories
- PRDs
- MVP definition
- Prioritization

## Phase 2 — Data & AI Foundations
- Python
- SQL
- Data visualization
- ML fundamentals
- Generative AI
- Prompt engineering
- AI agents
- APIs
- AI evaluation

## Phase 3 — AI Product Execution
- AI feature specifications
- Model selection
- Data requirements
- Evaluation plans
- Human-in-the-loop design
- AI UX
- Monitoring
- Cost / latency trade-offs

## Phase 4 — Product Analytics
- North Star Metric
- Activation
- Adoption
- Retention
- Conversion
- Experimentation
- A/B testing
- Funnel analysis

## Phase 5 — Portfolio Proof
Target portfolio artifacts:

1. GenAI product case study
2. AI PRD
3. AI product roadmap
4. Product analytics case study
5. AI evaluation case study
6. Working AI prototype
7. Product strategy memo
8. Experiment analysis

## Portfolio Principle

Do not present AI projects only as technical implementations.

Present them as:

**Problem → User → Opportunity → Solution → AI → UX → Metrics → Experiment → Learning**
