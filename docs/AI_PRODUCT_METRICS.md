# AI Product Metrics

## Product Health

### Acquisition
- Qualified visitors
- Signup conversion
- Cost per acquisition

### Activation
- Time to first value
- First successful AI task
- Activation rate

### Engagement
- Weekly active users
- Feature adoption
- Tasks per active user
- Repeat usage

### Retention
- D7 / D30 retention
- Repeat task completion
- Churn

## AI Quality

Choose metrics appropriate to the use case:

- Accuracy
- Precision
- Recall
- F1
- mAP
- Groundedness
- Hallucination/error rate
- Human acceptance rate
- Latency
- Reliability

## Business

- Cost per task
- Automation rate
- Time saved
- Conversion
- Revenue impact
- Support-ticket reduction

## Guardrails

AI products also need:

- Safety incidents
- Privacy issues
- Failure rate
- Escalation rate
- Model/API cost
- Latency thresholds

## PM Rule

Never claim an AI product is successful from model accuracy alone.

Connect:

**AI quality → user behavior → business outcome**
